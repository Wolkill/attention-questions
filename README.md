# Задача на внимание

Сайт-отчёт о встрече Школы ЭШЭР про внимание (3 октября 2026, 17:00–21:00). Шуточная пандемия СДВГ и три версии того, как она передаётся: рилсы, дискоммуникация и зловредное поле.

## Что внутри

- `index.html` — вся страница: разметка, стили и немного JavaScript (просмотр плакатов крупно и рисунок «поток внимания»). Сборка не нужна.
- `assets/posters/` — фото итоговых плакатов, выровненные и сжатые. У каждого две версии: `-sm` для страницы и крупная для просмотра, в JPEG и WebP.
- `assets/og.jpg` — картинка-превью для ссылок в мессенджерах и соцсетях.

Текст восстановлен по живой расшифровке (аудиозапись не велась) и фотографиям плакатов.

## Как посмотреть

Открыть `index.html` в браузере.

## Как опубликовать на GitHub Pages

1. В репозитории открыть Settings → Pages.
2. В Source выбрать Deploy from a branch, ветку `main` и папку `/ (root)`.
3. Через пару минут сайт откроется по адресу https://wolkill.github.io/attention-questions/

Превью ссылки (`og:image`) настроено на этот адрес. Если сайт будет жить в другом месте, поменяйте адрес в `<meta property="og:image">` в `index.html`.
